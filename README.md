## 📖 Overview

RestaurantOS is a modern **AI-powered Restaurant ERP System** built to streamline restaurant operations through a single integrated platform.

The system helps restaurant owners efficiently manage:

- Orders
- Inventory
- Kitchen Operations
- Staff
- Attendance
- Leave Management
- Expenses
- Customer Feedback
- Business Analytics
- AI-powered Insights

RestaurantOS is designed with a clean, responsive interface and real-world restaurant workflows in mind.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/RestaurantOS.git
```

---

## Install Frontend

```bash
cd client

npm install
```

---

## Install Backend

```bash
cd server

npm install
```

---

## Configure Environment Variables

Create `.env` inside **server**

```env
DATABASE_URL=YOUR_DATABASE_URL

JWT_SECRET=YOUR_SECRET

GEMINI_API_KEY=YOUR_API_KEY
```

---

## Start Backend

```bash
npm run dev
```

---

## Start Frontend

```bash
npm run dev
```
